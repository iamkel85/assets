# Onde · colour ramps

Eight ramps, eleven steps each, plus the print ground. Raw values only, no semantic roles: map them to your own roles.

Same values as the Onde brand manual v1.1, pages 32 and 36, and 1:1 with the Figma variables in the delivered file.

| File | Use |
| --- | --- |
| `onde-colour-ramps.json` | Flat map, keyed exactly like the Figma variables |
| `onde-colour-ramps.tokens.json` | W3C Design Tokens format, for token pipelines |
| `onde-colour-ramps.css` | Custom properties, ready to drop into a stylesheet |

The three brand colours sit at `brand/navy/900` (Midnight Navy), `brand/water/300` (Greek Water) and `brand/gold/400` (Stellar Gold). White Digital and Dark Ink close the neutral ramp at `000` and `900`.
